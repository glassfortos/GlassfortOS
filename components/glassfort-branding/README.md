# glassfort-branding

The Glassfort logo (D-24 in [`docs/DECISIONS.md`](../../docs/DECISIONS.md)),
specified in
[`docs/03-desktop-design.md`](../../docs/03-desktop-design.md#logo).
Plymouth, login and lock screen artwork will follow here.

The logo is a trademark and not covered by the project licences; see
[`TRADEMARKS.md`](../../TRADEMARKS.md) and `LICENSE-logo`.

## The logo

A glass fortress tower in Glacier Teal → Fort Indigo (D-22): a crown with
three rounded crenellations, a tapered tower body and one frosted front
pane. It is our own vector redraw of the maintainer's draft. Compared
with the draft it has fewer overlapping panes (crown, body, one pane
instead of five), so it stays legible at small sizes. The overlap of
crown and body is drawn lighter, like stacked glass.

| File | Use |
|---|---|
| `glassfort-symbol.svg` | Full-colour symbol on light backgrounds |
| `glassfort-symbol-dark.svg` | Full-colour symbol on dark backgrounds (fine light edges) |
| `glassfort-app-icon.svg` | App icon: Midnight squircle, symbol 60 % of its height; installed as hicolor icon `glassfort` |
| `glassfort-mono-dark.svg`, `glassfort-mono-white.svg` | Flat symbol for 16–32 px, the pane is cut out |
| `glassfort-lockup-horizontal{,-dark}.svg` | Symbol + wordmark side by side |
| `glassfort-lockup-stacked{,-dark}.svg` | Symbol above the wordmark |

Everything is installed to `/usr/share/glassfort/branding/`.

## Generating

All SVGs are generated by `generate` from a few shapes on a 256 grid.
Never edit them by hand.

```sh
./generate          # rewrite the SVGs
./generate --check  # CI: SVGs up to date
```

Only SVG features that Qt's SVG renderer supports are used (no masks,
filters or CSS), because Plasma renders icons with QtSvg. Checked with
QtSvg 6.11 and librsvg at 16, 32 and 256 px.

The wordmark is "Glassfort" in Inter Semibold as outlines, so the files
need no font. The outlines are stored in `wordmark-inter-semibold.txt`.
To re-extract them (needs `fonttools` and `uharfbuzz`):

```sh
./generate --wordmark-font /usr/share/fonts/inter/InterVariable.ttf
```

After a change, update the `sha256sums` in the PKGBUILD (`updpkgsums`).

## Login screen (SDDM)

The SDDM theme `glassfort` (`/usr/share/sddm/themes/glassfort/`) is
Plasma's Breeze login screen with Glassfort artwork: its
`metadata.desktop` points `MainScript` at `../breeze/Main.qml`, so only
the configuration is ours and the QML stays in step with Plasma.
`theme.conf` sets the dark Glassfort wallpaper as background, Midnight as
fallback colour and the horizontal lockup (white wordmark) as logo.
`/etc/sddm.conf.d/10-glassfort.conf` selects the theme; a choice made in
System Settings (sddm-kcm writes `kde_settings.conf`) wins.

Breeze shows the logo at the bottom centre while the screen is idle,
so the background has no logo of its own: a logo in the middle would sit
behind the user picture and the password field.

SDDM reads these files with QSettings, so they carry no comments.

Checked with `sddm-greeter-qt6 --test-mode` in an invisible KWin.
