# Components

One folder per package. Each folder contains the package source, a
`PKGBUILD`, a short `README.md` and its tests. Packages built from here are
published in the `[glassfort]` repository.

Packages that Glassfort carries because they only exist in the AUR live in
`third-party/` and keep their upstream licences.

See [`docs/01-architecture.md`](../docs/01-architecture.md) for the planned
list of components and their responsibilities.
